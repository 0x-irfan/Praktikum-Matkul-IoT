Buatlah program di dalam lingkungan simulasi (SIL) dengan ketentuan sebagai berikut:
1. Konfigurasikan ESP32 dengan satu LED. Buat LED menyala dengan interval 1 detik, 2 detik, dan 3 detik menggunakan delay () dan timer millis ().
2. Konfigurasikan ESP32 dengan 3 LED. Buat LED menyala running dari kiri ke kanan secara looping.
3. Konfigurasikan ESP32 dengan 3 LED. Buat LED menyala running dari kanan ke kiri secara looping.
4. Konfigurasikan ESP32 dengan 3 LED dan 3 Button.
    - Ketika Button 1 ditekan, maka LED akan menyala blink.
    - Ketika Button 2 ditekan, maka LED akan running dari kiri ke kanan secara looping.
   -  Ketika Button 3 ditekan, maka LED akan running dari kanan ke kiri secara looping.

Laporan dibuat dalam format video (kreatif), diupload ke medsos masing-masing (TikTok). Pengumpulan ke class room dalam bentuk link. Pastikan akun dibuat public.
